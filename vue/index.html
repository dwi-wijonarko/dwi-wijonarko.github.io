Bagian A 01 / 08

Instalasi, Konfigurasi & Memulai Vue

Ada tiga cara untuk memulai proyek Vue: menggunakan CLI, CDN, atau NPM. Pilih cara yang paling sesuai dengan kebutuhan Anda.

Vue CLI

Cara paling lengkap untuk membangun proyek Vue. Membutuhkan Node.js terpasang.

# instalasi CLI
npm install -g @vue/cli
# buat proyek
vue create first-vue
# pilih Vue 3
cd first-vue
npm run serve
Butuh koneksi internet & Node.js. Jalankan sebagai Administrator bila ada kendala sekuriti.

CDN

Cara paling cepat untuk mencoba Vue. Cukup sertakan tag script di HTML.

<div id="app"></div>
<script src="https://unpkg.com/vue@next"></script>
<script>
const { createApp } = Vue;
const App = {
data() { return { name: "Vue CDN" }; },
template: `<h1>Halo {{ name }}!</h1>`
};
createApp(App).mount("#app");
</script>

NPM

Untuk proyek yang lebih terstruktur, gunakan NPM dan referensikan file lokal.

npm init -y
npm install vue@next --save-dev
<script src="node_modules/vue/dist/vue.global.js"></script>
# file HTML harus satu rute
# dengan folder node_modules
Setelah npm run serve, aplikasi bisa diakses di localhost:8080

Bagian B 02 / 08

Struktur Proyek Vue

Vue CLI membuat kerangka direktori yang rapi. Pahami setiap bagian agar mudah mengelola kode.

File di Root

babel.config.js Konfigurasi Babel — transpiler JavaScript ke versi yang lebih lama untuk kompatibilitas browser.
package.json Konfigurasi proyek JavaScript, daftar dependencies, dan script.
README.md Dokumentasi singkat proyek.

Direktori Penting

node_modules/ Menyimpan paket-paket pustaka yang dipasang via npm.
public/ Menyimpan file HTML utama yang akan menjadi tampilan dasar.
src/ Menyimpan kode sumber aplikasi Anda.
src/main.js Entry point yang menghubungkan public/index.html dengan komponen utama.
src/components/ Tempat menyimpan definisi komponen Vue (.vue).
src/assets/ File gambar, multimedia, dan aset lainnya.

Tip: Vue UI

Anda juga bisa mengelola proyek Vue via GUI berbasis browser. Jalankan perintah vue ui di terminal, dan Vue akan membuka dashboard proyek di browser. Semua yang bisa dilakukan di shell juga bisa dilakukan di GUI.

Rendering Deklaratif

Vue memproses keluaran ke DOM secara deklaratif menggunakan template {{ }}. Coba ubah kode di bawah dan tekan Jalankan untuk melihat hasilnya langsung.

Penjelasan

  • {{ name }} akan diganti dengan nilai dari name di state data().
  • Directive mounted() adalah lifecycle hook yang dipanggil setelah komponen dirender ke DOM.
  • setInterval menambah nilai counter setiap 1000ms (1 detik). Karena Vue reaktif, DOM otomatis di-update.
Praktik 04 / 08

Interaksi dengan Pemakai

Vue menggunakan directive v-on:<event> untuk menangani event. Sebagai contoh, v-on:click menangani klik tombol. Klik tombol di preview untuk membalik string!

interaksi-pemakai.html
Preview Live
localhost

Penjelasan

  • v-on:click="reverseStr" mendaftarkan event listener untuk klik tombol.
  • Saat tombol diklik, fungsi reverseStr di dalam methods dijalankan.
  • split('').reverse().join('') memecah string jadi array karakter, membalik urutannya, lalu menggabungkan kembali.
  • Shorthand: @click="reverseStr" sama dengan v-on:click="reverseStr".
Praktik 05 / 08

Struktur Kendali: v-if

Directive v-if digunakan untuk rendering kondisional. Elemen hanya ditampilkan jika kondisi bernilai true.

v-if.html
Preview Live

Penjelasan

  • v-if="terlihat" hanya merender elemen <p> jika terlihat bernilai true.
  • Tombol mengubah state terlihat dan teks aksi secara bersamaan.
  • Perhatikan logika onOff(): bila teks tombol "Sembunyikan", ubah menjadi "Tampilkan" dan sembunyikan paragraf.
  • Vue juga menyediakan v-else dan v-else-if untuk percabangan lebih kompleks.
Praktik 06 / 08

Perulangan dengan v-for

Directive v-for digunakan untuk menampilkan daftar item dari array. Setiap item harus memiliki key unik agar Vue bisa melacak perubahan secara efisien.

v-for.html
Preview Live
localhost

Penjelasan

  • v-for="mk in daftarMK" mengiterasi setiap item dalam array daftarMK.
  • v-bind:key="mk.text" memberi Vue cara untuk melacak setiap item secara unik. Bisa disingkat :key.
  • Anda juga bisa mendapatkan index: v-for="(mk, index) in daftarMK".
  • Wajib menggunakan key yang unik untuk performa dan stabilitas rendering.
Praktik 07 / 08

Komponen Dasar

Komponen memperluas HTML dengan tag-tag baru yang dapat dipakai ulang. Kita bisa mendaftarkan komponen dengan app.component() dan menyertakannya di template seperti tag HTML biasa.

komponen-dasar.html
Preview Live
localhost

Penjelasan

  • app.component('daftar-mk', {...}) mendaftarkan komponen baru dengan tag <daftar-mk>.
  • props: ['mk'] mendeklarasikan atribut kustom yang bisa diterima komponen dari induknya.
  • v-bind:mk="mkDitawarkan" mengirim data ke komponen via props.
  • Template komponen bisa berisi HTML apa pun, termasuk komponen lain (komposisi).
  • Nama komponen dalam HTML harus kebab-case: daftar-mk, bukan daftarMk.
